AtomMatrixWeather インストール

M5Stack ATOM Matrix にブラウザから直接ファームウェアを書き込みます。Arduino IDE は不要です。

ファームウェア: __VERSION__

事前に確認
  • ブラウザは Chrome または Edge (PC 版) を使ってください。Safari / Firefox / スマホは非対応です
  • Mac の場合、USB シリアルドライバ (CH9102 / CH552) が必要なことがあります。ATOM が認識されない場合は M5Stack のドライバページ からインストールしてください
  • データ通信できる USB-C ケーブルで接続してください (充電専用ケーブルは不可)
  1. ATOM Matrix を USB で PC に接続する
  2. 下のボタンを押し、表示されたシリアルポートを選んで「接続」する
  3. 「INSTALL」を選ぶ。既に設定済みの機体で Wi-Fi 設定を消したい場合だけ「Erase device」にチェックを入れる
このブラウザは Web Serial に対応していません。PC 版の Chrome / Edge で開いてください。 HTTPS で開く必要があります。
書き込み後

初回は自動で設定モード (LED が青く回転) になります。スマホ/PC から Wi-Fi AtomWeather-XXXX に接続し、Wi-Fi と都道府県を設定してください。 詳しい手順は README を参照してください。
